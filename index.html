Fleet

aliases stored in this browser
Browsers cannot read a BLE MAC address. Web Bluetooth withholds it by design, and on macOS the OS never exposes it at all — Chrome only hands out an opaque per-profile id (the grey code, click to copy). So enter the MAC your controller shows in the amber field and the roster becomes your MAC-to-drone map. Pair each drone once, label it, then connect by that row — it skips the picker entirely.

Protocol measured against hardware, not vendor-supplied — 8-byte control frame [hdr, roll, pitch, yaw, thrust, buttons, 0, 0], byte 0 is a header and not an axis. Buttons: 24 takeoff · 72 land · 40 aux · 136 stop. Sticks map ≤100 → v−100, 100–155 → 0, >155 → v−155. Telemetry is 9 big-endian uint16 biased by +32768. Baro is flagged because it reads noise on the bench. Hardware notes: 01studio wiki.
